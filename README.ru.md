# homebridge-rinnai-local

[English](README.md)

Плагин Homebridge для газовых котлов Rinnai с Wi-Fi-пультом **WF-100W** (проверено на WF-100W_EU + котёл REB-KAI3135FF, приложение «My Rinnai», Италия).

Плагин работает как посредник между пультом и облаком Rinnai:

```
пульт WF-100W ──HTTP:9105──▶ Homebridge (этот плагин) ──▶ облако Rinnai
```

- состояние котла читается из пакетов пульта и показывается в HomeKit;
- команды из «Дома» подмешиваются в ответ пульту (меняются только нужные байты);
- ответы облака передаются пульту как есть — приложение My Rinnai продолжает работать;
- если облако недоступно, плагин отвечает пульту сам.

В «Доме» появляются два термостата: **Heating** (отопление, 10–40 °C, по теплоносителю 40–80 °C) и **Hot Water** (горячая вода, 35–60 °C). Названия меняются параметрами `heatingName` / `hotWaterName`.

Протокол — по [sasamix/ha-rinnai-boiler](https://github.com/sasamix/ha-rinnai-boiler) (MIT).

## Перенаправление пульта

Пульт сам ходит на сервер облака по TCP 9105. Итальянский пульт — на `37.206.147.54` (Telecom Italia), а не на `wifiboilers1.rinnai.co.kr`, поэтому подмена DNS не помогает — нужен NAT на роутере:

| Правило | Источник | Назначение | Перевод |
|---|---|---|---|
| DNAT | IP пульта | `37.206.147.54:9105` | `<IP Homebridge>:9105` |
| SNAT | IP пульта | `<IP Homebridge>:9105` | IP роутера |

SNAT нужен, когда пульт и Homebridge в одной подсети — иначе ответ придёт пульту с «чужого» адреса. После добавления правил пульт надо перезапустить по питанию (у него постоянное соединение).

## Настройка

```json
{
  "platform": "RinnaiLocal",
  "name": "Rinnai Boiler",
  "port": 9105,
  "mac": "",
  "readOnly": true,
  "cloudHost": "37.206.147.54",
  "cloudPort": 9105
}
```

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `mac` | пусто — принять любой | MAC пульта, 12 hex |
| `heatingName` / `hotWaterName` | `Heating` / `Hot Water` | имена плиток; «Дом» запоминает имя при добавлении, поэтому смена имени создаёт новый аксессуар |
| `powerSwitches` | `false` | термостаты только «нагрев», вкл/выкл — отдельные выключатели `<имя> Power`. Siri на «turn off the AC» иначе выключает котёл |
| `readOnly` | `true` | только чтение, команды котлу не отправляются |
| `cloudProxy` | `true` | пересылать пульт в облако |
| `cloudHost` / `cloudPort` | `37.206.147.54` / `9105` | адрес облака (IP, не имя) |

Проверка: `curl localhost:9105/health`. Ручная команда (только с самой машины): `curl -X POST 'localhost:9105/local/hw?t=50'`.

## Тесты

```sh
node test/test.js
```

Сначала `npm install`. Тест поднимает плагин и поддельное облако на 19105–19107, гоняет регистрацию, чтение, команды, проксирование и падение облака.

Это программа для управления газовым прибором, не связана с Rinnai. Используйте на свой риск.
