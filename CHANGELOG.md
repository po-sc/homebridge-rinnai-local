# Changelog

## 1.0.1

- Releases are published to npm from GitHub with provenance (trusted publishing).

## 1.0.0

- First public release.
- English default tile names (`Heating`, `Hot Water`); the old Russian defaults keep their accessory IDs.
- `powerSwitches`: thermostats offer Heat only, on/off moves to separate switches (Siri "turn off the AC" no longer turns the boiler off).
- `heatingName` / `hotWaterName` options.
- Cloud proxy: the My Rinnai app keeps working; local fallback when the cloud is down.
